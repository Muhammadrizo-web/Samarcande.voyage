# Samarcande Voyage — сайт агентства (v2)

Next.js 16 · React 19 · TypeScript strict · Tailwind CSS 4 · статический экспорт.
4 языка (FR · EN · RU · DE) с переведёнными URL, светлая и тёмная тема, анимации на чистом CSS
(без библиотек), калькулятор цены, бронирование с отправкой в Telegram + e-mail.

---

## 1. Запуск

```bash
npm install
npm run dev          # http://localhost:3000/fr/
npm run build        # готовый сайт в папке out/
npm start            # раздать out/ локально (как на хостинге)
```

Node 20.9+.

**Даты 2027:** скопировать строку в `DEPARTURES` (`src/content/tour.ts`), поменять код, даты и цену.
Прошедшие выезды исчезают с сайта сами. Если до выезда меньше 30 дней, он помечается как «горящий»
и оплачивается целиком. Если меньше 3 дней, он скрывается. Когда открытых выездов нет, вместо списка
показывается форма «узнайте первыми» (лист ожидания).

**Минимум людей в заявке:** `BOOKING.minPaxPerBooking` в `src/content/tour.ts`.
`1` — пара или соло может присоединиться к группе. `3` — только от трёх человек.
Ответ в FAQ меняется автоматически. **Уточнить у агентства до запуска.**

**Фото:** положить JPG с тем же именем в `assets/photos/` и выполнить `npm run images`.
Скрипт сделает AVIF, WebP и JPG в 5 размерах плюс размытое превью. Нужны оригиналы от 2400 px:
сейчас герой всего 1600 px, и на больших экранах он мягкий. Фото Ташкента — 2048 px, этого хватает.


## 2a. Секции: «одно движение колеса = одна секция» (v2.2)

Режим задаётся одной строкой: `UI.sectionMode` в `src/content/site.ts`.

| Значение | Что происходит на компьютере |
|---|---|
| `'page'` (сейчас) | Один щелчок колеса, один жест тачпада или PageDown — плавный переход ровно к началу следующей секции (0,6–1 с). |
| `'curtain'` | Обычная прокрутка, следующая секция наезжает поверх предыдущей (версия 2.1). |
| `'scroll'` | Обычная прокрутка без эффектов. |

Как работает режим `'page'` (`src/components/client/Screens.tsx`):

- **Мышь.** Один щелчок колеса — одна секция. Несколько быстрых щелчков подряд тоже дают одну
  секцию, поэтому страница не «улетает».
- **Тачпад.** Один жест — одна секция. Инерция тачпада не перескакивает через секции.
- **Клавиатура.** ↓ ↑, PageDown / PageUp, пробел, Home, End. В полях формы, в списке дней
  и в меню клавиши работают как обычно.
- **Ctrl + колесо** (масштаб страницы) и горизонтальная прокрутка ленты фото не перехватываются.
- **Высокие секции.** Если секция всё же выше экрана (очень низкое окно), она сначала
  прокручивается частями, потом начинается следующая. Контент никогда не обрезается.
- **Конец страницы.** Последний шаг ведёт к блоку «Забронировать» и подвалу.
- **Шапка** в этом режиме не прячется.
- **Индикатор справа** «03 / 09»: клик по точке ведёт ровно к этой секции.
- **Выключено автоматически:** на телефонах и планшетах (обычная прокрутка пальцем), при
  системной настройке «уменьшить движение», на страницах форм и юридических страницах.

**Экраны проверены** (каждая секция помещается целиком, без обрезки): 2560×1300, 1920×940,
1536×730, 1470×830 (MacBook Air), 1440×790, 1366×657, 1280×620, 1024×640.
Телефоны и планшеты — 360, 390, 430, 768, 1024 px: нет горизонтальной прокрутки, кнопки ≥ 44 px.

  блок «Téléphone et tablette».

  светлый с тонкими линиями. Тёмная тема без изменений.

- **Цвета светлой темы.** Секции чередуются: Ivory `#F3F0E9` (`--bg`) и Nude `#E3DBCC` (`--bg-2`,

- **Фото Ташкента** — `assets/photos/city-tachkent.jpg` (2048 px). Появилось на карточке города,
  в ленте городов и на странице Ташкента.
- **Подвал** — крупная надпись «Samarcande Voyage».
- **FAQ** (`src/components/client/FaqList.tsx`). Открыт только один ответ: при открытии нового
  предыдущий закрывается. Открытие плавное (анимация высоты строки грида, работает во всех
  браузерах, а не только в Chrome). В две колонки каждая колонка независима, поэтому вопросы

Остальное из v2.1:

- **Фото** — прямоугольники со скруглением 22 px (`--r-img` в `src/app/screens.css`), арок больше нет.
- **Одна секция = один экран** на компьютере (от 1024 px в ширину и от 600 px в высоту).
  Формы (бронь, контакты, калькулятор дат) и юридические страницы — обычная прокрутка:

## 3. Публикация (Cloudflare Pages — бесплатно, коммерческое использование разрешено)

1. Залить проект на GitHub.
2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
3. Build command: `npm run build` · Output directory: `out`.
4. Settings → Environment variables:

   | Переменная | Значение |
   |---|---|
   | `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
   | `TELEGRAM_CHAT_ID` | id чата менеджера (написать боту, затем открыть `https://api.telegram.org/bot<TOKEN>/getUpdates`) |
   | `RESEND_API_KEY` | ключ resend.com (бесплатно до 3000 писем в месяц) |
   | `LEAD_EMAIL_TO` | почта, куда приходят заявки |
   | `LEAD_EMAIL_FROM` | `Samarcande Voyage <site@ваш-домен>` (домен подтвердить в Resend) |
   | `ALLOWED_ORIGIN` | `https://www.ваш-домен` |

5. Custom domains → подключить домен. Поменять `SITE.url` в `src/content/site.ts`.

Папка `functions/` — это серверная часть на Cloudflare:
- `functions/api/lead.ts` принимает формы и отправляет заявку в Telegram и на почту;
- `functions/index.ts` перенаправляет `/` на язык браузера.

Если Telegram и почта обе недоступны, форма не теряет заявку: она предлагает отправить её
в один клик по e-mail или в WhatsApp с уже заполненным текстом.

### Почта без домена (можно включить сегодня)

Resend разрешает отправку с адреса `onboarding@resend.dev` **только на почту владельца аккаунта** —
для уведомлений агентству этого достаточно:

1. Зарегистрироваться на resend.com на рабочую почту агентства (на неё и будут приходить заявки).
2. API Keys → Create API Key → скопировать ключ (`re_...`).
3. Cloudflare Pages → проект → Settings → Environment variables:
   `RESEND_API_KEY` = ключ, `LEAD_EMAIL_TO` = та же почта агентства.
   `LEAD_EMAIL_FROM` **не задавать** — тогда письмо уйдёт с `onboarding@resend.dev`.
4. Deployments → Retry deployment (переменные подхватываются только при новой сборке).
5. Отправить тестовую заявку с сайта и проверить почту, в том числе папку «Спам».

Когда домен куплен и подтверждён в Resend (Domains → Add domain → DNS-записи в Cloudflare),
задать `LEAD_EMAIL_FROM = Samarcande Voyage <site@ваш-домен>` — письма начнут приходить
с адреса агентства и перестанут попадать в спам. Тогда же можно писать на любые адреса,
а не только на почту владельца аккаунта.

**Формы работают только на опубликованном сайте.** При `npm run dev` и при открытии папки `out/`
с диска обработчика `/api/lead` нет: форма покажет запасной вариант (письмо или WhatsApp).

Другой хостинг (Vercel, Netlify, свой сервер): папка `out/` работает где угодно. Сам обработчик
заявок нужно перенести на платформу хостинга, а его адрес указать в `NEXT_PUBLIC_LEAD_ENDPOINT`.

## 5. SEO — что уже сделано

- Каждая страница на каждом языке — готовый HTML (68 страниц), со своим URL, `canonical` и `hreflang` (плюс `x-default`).
- `sitemap.xml` с языковыми альтернативами, `robots.txt`, `manifest.webmanifest`.
- schema.org: `TravelAgency`, `TouristTrip` с программой по дням и `Offer` на каждый выезд, `FAQPage`,
  `TouristDestination` для городов, `BreadcrumbList`.
- 6 отдельных страниц городов на 4 языках — под поисковые запросы вида «Boukhara que voir», «Chiwa Sehenswürdigkeiten».
- Open Graph и Twitter-карточки, иконки, светлая и тёмная `theme-color`.
- Шрифты на своём сервере, без Google Fonts: это требование DSGVO для немецкой аудитории.
- Lighthouse: компьютер — Performance 99; мобильный (эмуляция медленного 4G) — 88–95. Accessibility, Best Practices и SEO — 100.

## 6. SEO — что код не сделает (это 70% результата)

1. Google Search Console и Bing Webmaster: подтвердить домен, отправить `sitemap.xml`.
2. Google Business Profile на офис в Самарканде (адрес, фото, часы работы).
3. Отзывы: Google и TripAdvisor. Просить каждую группу в последний день тура.
4. Контент раз в 2 недели: «Ouzbékistan en octobre», «budget voyage Ouzbékistan», «visa Ouzbékistan 2027»…
5. Ссылки на сайт: французские форумы путешественников (Routard), блогеры, партнёрские агентства.
6. Цель на первые 6 месяцев — узкие запросы (long tail). Не «circuit Ouzbékistan»: там стоят Atalante, Nomade Aventure и Jet Tours.
